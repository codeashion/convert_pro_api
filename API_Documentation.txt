CALENDAR API - COMPLETE API DOCUMENTATION WITH CURL COMMANDS
================================================================

Base URL: http://localhost:8000/api
Server Status URL: http://localhost:8000

AUTHENTICATION HEADER:
All protected endpoints require: --header "token: YOUR_JWT_TOKEN_HERE"

================================================================
1. SERVER STATUS
================================================================

Title: Check Server Status
Description: Verify if the server is operational
Method: GET
URL: /

CURL Command:
curl -X GET "http://localhost:8000/"

Expected Response:
{
  "message": "Welcome to the API. The server is operational."
}

2. AUTHENTICATION ENDPOINTS
================================================================

Title: User Registration (Signup)
Description: Register a new parent user with family members
Method: POST
URL: /api/auth/signup

CURL Command:
curl -X POST "http://localhost:8000/api/auth/signup" \
  --header "Content-Type: application/json" \
  --data '{
    "full_name": "John Doe",
    "email": "john.doe@example.com",
    "password": "securepassword123",
    "confirm_password": "securepassword123",
    "family_members": [
      {
        "member_name": "Alice Doe",
        "date_of_birth": "2015-03-15",
        "assigned_colour": "#FF5733",
        "image_path": null,
        "voice_recording": null
      }
    ]
  }'

Expected Response:
{
  "statusCode": 201,
  "status": true,
  "message": "User created successfully",
  "data": {
    "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
    "token_type": "bearer",
    "parent": {
      "id": 1,
      "full_name": "John Doe",
      "email": "john.doe@example.com",
      "family_members": [...]
    }
  }
}

11. FILE UPLOAD ENDPOINT
================================================================

Title: File Upload
Description: Global file upload endpoint for various categories
Method: POST
URL: /api/upload/

CURL Command:
curl -X POST "http://localhost:8000/api/upload/" \
  --header "token: YOUR_JWT_TOKEN_HERE" \
  --form "category=task_icons" \
  --form "file=@/path/to/your/file.jpg"

Categories Available:
- task_icons: For task icon images
- task_audio: For task audio files
- reminder_audio: For reminder audio files
- profile_images: For parent profile images
- documents: For document uploads

Expected Response:

================================================================
NOTES
================================================================

1. Replace YOUR_JWT_TOKEN_HERE with the actual JWT token received from login
2. Replace ADMIN_JWT_TOKEN_HERE with an admin user's JWT token for admin endpoints
3. All dates should be in YYYY-MM-DD format
4. All times should be in HH:MM:SS format (24-hour format)
5. File uploads require multipart/form-data content type
6. All JSON requests require Content-Type: application/json header
7. The server runs on localhost:8000 by default
8. API prefix is /api for all endpoints except the root status endpoint
